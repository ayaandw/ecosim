# EcoSim
An educational simulation game where players choose climate actions in order to improve their city's environment while managing budget, public opinion, and resources

## How to Play
* **Survive:** Balance a $15M budget, water reserves, and approval ratings without letting approvals drop to 0% or going to -$25M
* **Build and Policies:** Construct buildings on the grid enact a polciy per term to guide city development
* **Review Annually:** Read the year-end report and manage loans and other events.
* **Go to tutorial for more detail**

## Features
* Managing 3 demographics with reward and protest mechanics
* Realistis economic principles like bonds, budgets, compounding interest, deficit spending, and credit ratings
* Yearly invoices and game-end report cards, and game-end data export capability

## Development
* Built with Python and Streamlit plugin
* Used Pandas for data export at conclusion of simulation
